# Frontend

Vue 3 + Vite на Feature-Sliced Design.

## Слои

Сверху вниз: `app → pages → entities → shared`. Импорт разрешён только вниз (или внутри своего слоя через публичный API слайса).

Слои `widgets` и `features` не заводим заранее. Они появляются, когда блок реально используется на нескольких страницах или содержит самостоятельное действие и состояние.

| Слой | Что лежит |
| --- | --- |
| `app` | точка входа, роутер, глобальные стили, layout: `App.vue`, `AppHeader`, `AppFooter` |
| `pages` | экраны `home` и `booking`; секции и контент конкретного экрана |
| `entities` | доменные модели, нужные нескольким страницам: `format` |
| `shared` | UI-кит (`ui`) и конфиг приложения (`config`), без знания о страницах |

## Правила

- У каждого слайса есть `index.ts` — публичный API. Импорт из другого слоя только через него: `@/entities/format`, а не `@/entities/format/model/formats`.
- Слайсы одного слоя не импортируют друг друга (кроме `shared`, где сегменты независимы).
- Внутри слайса — сегменты `ui`, `model`, `api`, `lib`, `config` по необходимости.
- Секции главной живут в `pages/home/ui/sections`, их контент — в `pages/home/model/content.ts`. Не выносить секцию в отдельный слой, пока она используется только на этой странице.
- Компонент, нужный одной странице, остаётся в её `ui`. В `shared/ui` попадает только то, что переиспользуется в разных местах без знания о странице и домене.
- Тесты — рядом с кодом в `__tests__`; один тест: `npx vitest run --root apps/frontend src/pages/home/ui/__tests__/HomePage.spec.ts`.
- Границы слоёв проверяет `src/__tests__/architecture.spec.ts` — он падает при импорте вверх или глубоком импорте через `@/`.

## Новый экран

1. `pages/<name>/ui/<Name>Page.vue` + `pages/<name>/index.ts`.
2. Маршрут в `app/router/index.ts`.
3. Секции и тексты держать внутри страницы: `pages/<name>/ui` и `pages/<name>/model`.
4. Если блок понадобился на второй странице — вынести в `shared/ui` или завести `widgets`. Если появилось действие с состоянием — завести `features`. Доменная модель, общая для страниц, идёт в `entities`.
